# Embedded Linux Engineering Lab

A structured Embedded Linux engineering repository focused on Linux Kernel debugging, BSP development, Linux Device Drivers, Device Tree customization, Boot Flow analysis, QEMU virtualization, Yocto, and embedded software integration.

This repository documents practical engineering exercises, debugging workflows, and reproducible labs built to strengthen system-level understanding of Embedded Linux development.

---

# Repository Objectives

- Study Linux Kernel internals
- Understand BSP architecture and board bring-up
- Practice Linux Device Driver development and debugging
- Analyze Linux boot flow
- Debug Device Tree issues
- Investigate kernel panic and memory-related failures
- Understand communication protocols (I2C, SPI, UART, PCIe)
- Build reproducible Embedded Linux environments
- Document engineering workflows and debugging techniques
